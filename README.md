# 薪跳 · 打工人的工资计时器

输入月薪、上下班时间和排班方式，实时查看下班倒计时、今日已赚金额、每秒收入与工作进度。页面支持手机和桌面浏览器；小牛会沿进度条前进，电脑屏幕上的打工人文案每天更换。

## 功能

- 按当月实际日期计算双休、单休或无休的工作天数。
- 实时更新下班倒计时、今日收入及每秒收入。
- 根据工作进度显示小牛动画；点击小牛可查看不同的进度提示。
- 设置保存在当前浏览器的 `localStorage`，刷新后仍会保留，无需账号或后端。
- 适配手机和桌面屏幕，支持减少动态效果的系统偏好。

## 本地运行

项目是纯静态网页，不需要安装依赖。在项目目录下启动一个本地服务器：

```bash
cd dist
python -m http.server 4173
```

然后打开 <http://127.0.0.1:4173/>。也可以将 `dist/` 中的全部文件交给任意静态网站托管服务。

## 计算口径

- 本月工作天数按所选排班和当前月份的日历计算；双休排除周六、周日，单休排除周日，无休计入每天。
- 每日工资估算 = 税前月薪 ÷ 本月工作天数。
- 每秒工资估算 = 每日工资估算 ÷ 上下班时间跨度（秒）。
- 今日已赚金额按当天已经过去的工作时间估算，下班后封顶为当日工资。

金额仅供趣味参考，不扣除午休、税费、请假、节假日或加班等因素。

## 项目结构

- `dist/`：可直接部署的网页和图片素材。
- `art/`：小牛动画的原始图片条。
- `extract-gallop-frames.py`、`extract-run-frames.py`：从原始图片条提取动画帧的辅助脚本；运行它们需要 Pillow、NumPy 和 OpenCV。

页面插画和摆件包含 AI 生成素材。

## 微信小程序

仓库同时提供原生微信小程序版本，源码位于 `miniprogram/`。

1. 打开微信开发者工具，选择“导入项目”。
2. 项目目录选择本仓库根目录（工具会读取 `project.config.json`）。
3. 导入后确认项目 AppID 与你的小程序一致；上传或发布前也请核对 `project.config.json` 中的 AppID。

小程序无需后端和服务器域名，设置保存在微信本地存储中。
